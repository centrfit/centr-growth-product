Hooks
Shell commands that auto-run at lifecycle events like PreToolUse and PostToolUse.
Why for you: Your friction log shows repeated 'user_rejected_action' and 'excessive_changes' around bulk DB writes and deploys. A PreToolUse hook that gates production commands, plus a PostToolUse formatter for your TypeScript edits, removes the manual policing.
// .claude/settings.json { "hooks": { "PreToolUse": [{ "matcher": "Bash", "hooks": [{"type": "command", "command": "case \"$CLAUDE_TOOL_INPUT\" in *--prod*|*your-prod-host*|*UPDATE*|*DELETE*) echo 'PROD/DB command - confirm with user first' >&2; exit 2;; esac"}] }], "PostToolUse": [{ "matcher": "Edit|Write", "hooks": [{"type": "command", "command": "npx prettier --write $CLAUDE_FILE_PATHS 2>/dev/null; true"}] }] } }
